# 码镜隐私政策

**版本：2026.11.28**

**运营主体：北京星界力科技有限公司**（以下简称「我们」）

我们重视您的个人信息保护。本政策说明码镜（Codelume）及相关在线服务如何收集、使用、存储与保护您的信息。

## 1. 我们收集的信息

### 1.1 账号、投稿与互动
- 使用「通过 Apple 登录」时，我们通过 Supabase 验证身份，并处理 Apple 提供的账号标识以及可用的邮箱地址。您可以使用 Apple 的邮件转发地址。App 将登录会话保存在 macOS 钥匙串中。
- 您选择设置的昵称、简介、头像和背景图用于展示个人主页。投稿时，壁纸包、预览及作品信息会上传以供审核和分发。点赞、关注、下载和举报会产生相应记录。您确认协议时，服务端保存账号标识、同意的协议版本标识及时间。
- 联系客服时，我们处理您主动提供的联系方式和问题描述。如您有购买记录，我们处理交易标识、金额、退款状态和账号权益，以便核对订单或恢复权益。

### 1.2 本地壁纸和可选权限
- 导入 Mac 的壁纸、播放列表、屏幕配置及预览缓存保存在本机。把作品提交到社区时，才会上传本次投稿所选的内容。在「设置」的存储管理中可查看和清理本地资源。
- 音频响应壁纸可在您开启系统音频输入时，在本机分析正在播放的声音，驱动可视化效果。此功能使用系统音频输出。鼠标互动壁纸可使用指针位置和主键点击来产生视差或点击效果。
- 启用日历功能并授予系统权限后，壁纸引擎可使用您所选日历的事件标题和时间区间来切换画面。您可以变更所选日历或关闭访问。
- 提供天气壁纸功能的版本可使用您手动选择的地点，或在您授权定位后取得设备坐标。地点保存在本机，用于通过 Apple 的位置和天气服务查询天气。您可在 App 或 macOS 系统设置中管理相应权限。

### 1.3 联网请求
在线功能会向服务提供商发送完成请求所需的网络信息，例如 IP 地址、请求时间、作品标识和登录状态。此类信息用于分发文件、验证权限、排查错误和防止滥用。请避免在公开资料或投稿中填写身份证件、银行卡等敏感信息。

## 2. 信息的使用目的

我们使用上述信息用于：

- 提供、维护与改进壁纸浏览、下载、投稿、审核与账号功能；
- 身份验证、安全风控（如防止批量爬取、滥用上传）；
- 履行法律法规要求及处理投诉、侵权通知；
- 在获得同意的前提下发送与服务相关的重要通知。

## 3. 信息的共享与委托处理

我们不会出售您的个人信息。Apple 处理 Apple 登录及您选择使用的 Apple 服务；Supabase 提供身份验证和数据库服务；Cloudflare 承载网站、壁纸包与公开预览的存储和分发。有支付或退款交易时，Paddle 处理相应的支付资料和交易信息。您发布到社区的作品、预览和公开资料可供其他用户查看。

我们仅在提供相应服务所需范围内使用上述服务，也可能依法向有权机关提供必要信息。

## 4. 信息的存储与跨境

本地壁纸与设置保存在您的 Mac 上。联网使用的账号、投稿和互动数据由我们的服务及所用云服务处理，服务节点可能位于您所在国家或地区以外。我们按提供服务、安全、交易及法定义务所需的期限保存相应记录。您可以在 App 内申请注销账号；请求受理后，账号进入待注销状态，已登录会话失效。

## 5. 您的权利

在适用法律范围内，您有权：

- 查询、更正您的账号资料（可在应用内或通过邮件申请）；
- 撤回部分授权（可能导致部分功能不可用）；
- 申请删除账号及相关个人数据（法律法规另有规定的除外）；
- 就本政策提出问题或投诉。

请发送邮件至 **codelume@163.com**，我们将在合理期限内回复。

## 6. 未成年人保护

码镜主要面向成年人。若您为未成年人，请在监护人指导下阅读本政策并使用服务。我们发现未经监护人同意收集未成年人信息的，将尽快删除。

## 7. Cookie 与类似技术

官网（codelume.cn）可能使用浏览器本地存储或类似技术以记住语言偏好、维持会话。您可通过浏览器设置管理 Cookie。

## 8. 政策更新

我们在官网保留各版本正文。需要重新取得同意时，App 会在登录或启动后恢复会话时显示新版。阅读完正文后，您可以确认，或选择退出登录。只有提交同意后，服务端才会记录您接受了该版本。
