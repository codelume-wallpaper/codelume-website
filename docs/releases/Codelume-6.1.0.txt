Codelume 6.1.0

System wallpapers
• System wallpapers now have their own settings. Choose a screen saver mode and how long your Mac should be idle before it starts. Settings are saved locally and take effect the next time you apply a system wallpaper.
• Menu bar controls are now available in system wallpaper mode.
• Removed the preparation dialog when switching system wallpapers.
• Added the automation permission description for system wallpapers.

Profiles and uploads
• Adjusted the layout and proportions of the profile cover, avatar, text, and statistics.
• Improved access to works, followed accounts, and moderation.
• Wallpaper uploads open in a dialog again, with a revised toolbar.

Other improvements
• Backend read requests now use the service address for the corresponding region.
• If the home page carousel is empty, it retries after one minute.
